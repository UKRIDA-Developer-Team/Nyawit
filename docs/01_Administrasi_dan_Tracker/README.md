# 01 – Administrasi dan Tracker

| Berkas | Isi | Checkpoint |
|---|---|---|
| `CP00_Kontrak_Kerja.md` | kontrak kerja, peran, kanal, aturan rapat dan konflik | CP00 |
| `CP01_Matriks_Kandidat_Topik.md` | matriks tiga kandidat dan keputusan | CP01 |
| `Tracker_Checkpoint.csv` | CP00–CP13: bukti di repositori, PJ, status verifikasi | semua |
| `Logbook_<Nama>.csv` | logbook individual mingguan (kolom sesuai panduan bagian 7) | tugas mingguan |
| `Catatan_Keputusan.md` | log keputusan teknis | bukti pendukung |

Tracker resmi berada di Google Sheets pada folder kelompok (panduan bagian 4). Berkas CSV di sini adalah salinan yang dapat diimpor ke Google Sheets (File → Import). Kolom **Status verifikasi** hanya diubah oleh dosen/asisten.

Logbook sengaja dibiarkan kosong: setiap anggota menulis kegiatan **nyatanya sendiri** setiap minggu. Isi dengan bukti yang dapat dibuka, bukan sekadar nama kegiatan.
